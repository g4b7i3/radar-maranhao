# Coleta automática

Arquivos gerados todo dia pelo GitHub Actions (`.github/workflows/coletar-plataformas.yml`) com o texto das provas das plataformas que só abrem com JavaScript (Crono Esportes, SA Crono, Central da Corrida, Topchip, GuardaLugar) e dos calendários Road Runners e running.life (só para descobrir provas; não são aplicados sozinhos). Não edite à mão: a pesquisa diária lê estes arquivos e passa o que for do Maranhão para `public/data/radar.json`.
